# 🏗️ 游戏配置表 (Excel) 编辑规范指南

## 1. 基础文件规范

### 1.1 文件命名
*   **格式**：必须使用 **英文 PascalCase**（首字母大写），严禁使用中文、空格或特殊符号。
*   **示例**：
    *   ✅ `ItemConfig.xlsx`
    *   ✅ `EnemyData.xlsx`
    *   ❌ `道具表.xlsx`
    *   ❌ `Item Config.xlsx`
*   **存放路径**：所有 Excel 文件必须存放在 `Assets/Config/Excel` 目录下（或工具指定的目录）。

### 1.2 工作表 (Sheet) 命名
*   **格式**：必须使用 **英文**。最终生成的类名将是 `文件名_表名Config`。
*   **示例**：
    *   文件名 `Item.xlsx`，表名 `Weapon` -> 生成 `Item_WeaponConfig`。
*   **忽略规则**：
    *   如果表名以 `#` 开头（例如 `#Readme`、`#Draft`），工具将完全忽略该 Sheet，不生成任何代码或数据。
    *   可用于存放备注、计算公式或废弃数据。

## 2. 表格结构规范 (核心)

表格的前三行有严格定义，**绝对不可错位**：

| 行号 | 定义 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **第 1 行** | **字段名 (Variable)** | 对应代码中的变量名。必须是英文，驼峰命名，不可重复。 | `Id` / `Name` / `AtkValue` |
| **第 2 行** | **数据类型 (Type)** | 定义该列的数据类型（详见第3节）。必须小写。 | `int` / `string` / `float` |
| **第 3 行+** | **数据内容 (Data)** | 实际的游戏配置数据，从这一行开始读取。 | `1001` / `屠龙刀` / `99.5` |

**特别注意：**
*   **第一列必须是主键 (ID)**：工具默认将第一列作为 Key。
    *   ID 不能为空。
    *   ID 不能重复。
*   **注释列**：如果需要在表头添加中文注释，请将字段名（第1行）命名为以 `#` 开头（例如 `#Desc`），工具会自动跳过该列，不生成代码。

---

## 3. 支持的数据类型

在第 2 行填写类型时，请严格遵守以下拼写：

| 类型标识 | 说明 | 数据示例 | 备注 |
| :--- | :--- | :--- | :--- |
| `int` | 整数 | `100`, `-5` | 默认值为 0 |
| `float` | 小数 | `0.5`, `10.0` | 默认值为 0 |
| `double` | 双精度小数 | `0.12345` | 精度更高 |
| `long` | 长整数 | `123456789` | 用于时间戳或大数 |
| `string` | 字符串 | `Hello`, `道具描述` | 默认值为空字符串 |
| `bool` | 布尔值 | `true`, `false`, `1`, `0` | `1` 代表真，`0` 代表假 |
| `int[]` | 整数数组 | `1,2,3,4` | 使用英文逗号 `,` 分隔 |
| `float[]` | 小数数组 | `0.1,0.5,1.0` | 使用英文逗号 `,` 分隔 |
| `string[]` | 字符串数组 | `a,b,c` | 使用英文逗号 `,` 分隔 |

## 4. 编辑示例

### 示例 1：基础道具表 (Item_Base)

|   | A (ID列) | B | C | D (注释列) | E |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **Id** | **Name** | **Price** | **#Desc** | **Tags** |
| **2** | **int** | **string** | **float** | **string** | **string[]** |
| **3** | 1001 | HealthPotion | 50.5 | 这是回血药 | potion,heal |
| **4** | 1002 | Sword | 1000 | 新手剑 | weapon,atk |

> **说明**：
> *   D列字段名为 `#Desc`，工具生成代码时会忽略此列（不会生成 `public string #Desc`），仅作为策划在Excel里的备注。
> *   E列是数组，用逗号分隔。

## 5. 常见错误自查 (FAQ)

1.  **Q: 为什么生成的 JSON 是空的或者少了一行？**
    *   A: 检查 ID 列（第一列）是否为空。如果 ID 为空，工具会跳过整行。

2.  **Q: 为什么生成的代码报错？**
    *   A: 检查第 1 行字段名是否包含空格（如 `Max HP` 是错的，应为 `MaxHP`）。
    *   A: 检查第 1 行字段名是否以数字开头。
    *   A: 检查是否有重复的字段名。

3.  **Q: 数组怎么填？**
    *   A: 必须使用**英文逗号** `,` 分隔。不要使用中文逗号 `，`。

4.  **Q: Excel 打开时会有 `~$` 开头的临时文件，会报错吗？**
    *   A: 工具已做过滤处理，会自动忽略临时文件，无需担心。

5.  **Q: 如何暂时屏蔽某一行数据？**
    *   A: 将该行的 ID（第一列）清空即可。

## 6. 高级技巧

*   **使用公式**：Excel 的单元格支持公式（如 `=A3*10`），工具读取的是计算后的最终值。
*   **数据引用**：如果需要在表A中引用表B的ID，请确保类型一致（通常是 `int`）。
*   **布尔值简写**：为了输入方便，`bool` 类型推荐直接填 `1` (True) 或 `0` (False)。
