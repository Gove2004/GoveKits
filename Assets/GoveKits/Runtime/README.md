# GoveKits Runtime

运行时模块集合，涵盖 UI、Unit、网络、配置/存储、计时、工具集等。

## 主要子模块
- AI：AI/状态机等逻辑。
- Application：场景与简易 ECS 等应用层能力。
- Network：HTTP API、协议收发与 P2P/Peer 等网络能力。
- Setting：全局设置，如音频、语言、本地化等。
- Storage：资源加载与存档系统。
- UI：面板体系、MVI 示例等。
- Unit：游戏单元/属性/能力/标签/反应系统。
- Utility：通用工具（计时、对象池、日志、事件、单例等）。

各子目录拥有独立 README 说明，并在源码内提供 XML 注释以便 IDE 提示与二次开发。
