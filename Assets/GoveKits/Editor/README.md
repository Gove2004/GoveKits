# GoveKits Editor 工具

本目录包含若干 Unity 编辑器扩展，用于提升项目生产力：

- CMD：跨平台命令行调用与打开文件夹工具。
- Protobuf Generator：调用 protoc 将 .proto 生成 C# 代码。
- Excel2Json：将 Excel 表导出为 DTO 代码与 JSON 数据。
- Project：根据模板初始化项目目录结构与 .gitignore。

## 目录
- CodeGenerator/：Protobuf 相关工具与窗口。
- Excel2Json/：Excel 导表工具窗口及流程。
- Project/：项目结构初始化与 Git 忽略模板应用。

## 快速上手
- 菜单路径均位于：GoveKits/*。
- 根据各 README 指引配置路径后即可使用。
