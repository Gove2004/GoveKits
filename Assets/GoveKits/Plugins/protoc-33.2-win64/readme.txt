此软件包包含了协议缓冲编译器（protoc）的预编译二进制版本。该二进制文件适用于希望在非 C++ 语言中使用协议缓冲，但又不想自行编译 protoc 的用户。
安装方法很简单，只需将此二进制文件放到系统 PATH 中的某个位置即可。
如果您打算使用附带的已知类型，不要忘记也要将 'include' 目录的内容复制到某个位置，例如 '/usr/local/include/'。
更多的安装说明，请参阅我们的官方 GitHub 站点：https://github.com/protocolbuffers/protobuf
